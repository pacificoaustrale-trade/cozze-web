# COZZE MINERÍA — sitio web (borrador de prueba)

Sitio estático (HTML + CSS + JS), sin build. Estructura:

- `index.html` — página de inicio
- `styles.css`, `main.js` — estilos globales y comportamiento (menús, formulario de prueba)
- `assets/` — imágenes optimizadas y favicon
- `vercel.json` — configuración de despliegue

Probar en local: `npx serve .` y abrir http://localhost:3000

Pendientes: formulario real, versión EN, Política de Privacidad, datos entre [corchetes].
